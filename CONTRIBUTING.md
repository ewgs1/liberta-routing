# Изменения реестра

Состав сервисов и explicit-флаги находятся в registry/registry.json. Источники и очередь обзора — в registry/provenance.json. Существующие рабочие домены не удаляются из-за отсутствия нового замера.

Перед изменением маршрута изучите первичный источник и реальные сценарии, сравните результат с предыдущей версией, обновите route-lock с причиной и выполните npm run verify. Не импортируйте готовые сторонние списки.

Не публикуйте конфигурации узлов, подписки пользователей, токены, сырые диагностические отчёты и сведения о точках наблюдения. Выпуски подключаются после отдельных испытаний; автоматического изменения производственных подписок нет.
