# Аудит исходной системы

Исследованы присланные registry.json, build.mjs, service-canary.mjs, compare-lists.mjs, сохранённые профили и отчёты. Рабочий Smart v5 переименован в Liberta Routing v1. Его маршрутизация и DNS сохранены.

| Находка | Результат |
| --- | --- |
| В реестре 13 классов и 111 уникальных доменов; 45 попадают в явный direct | Полный состав и флаги классов сохранены и защищены контрольной суммой |
| Сборщик принимал зарубежные сбои без домашнего baseline; пустой baseline также снимал проверку | Исправлено: baseline обязателен, конкретный домен должен иметь ok/redirect |
| В исходном реестре были метаданные узлов | Исключены из публичного реестра; на сборку маршрутов это не влияет |
| Старый comparator учитывал explicit:false как явное покрытие | В текущем сравнении используются реальные 45 явных правил |
| В раскрытии категорий full мог заменить domain для того же имени | Дефект воспроизведён; внешний comparator не используется для изменения базы |
| Canary объявлял 403 блокировкой и допускал отключение проверки TLS | Новый наблюдатель не делает таких выводов, не отключает TLS и ничего не меняет в маршрутах |
| Диагностические отчёты и архитектурные документы содержат внутренние сведения | Оставлены закрытыми; в публичной части только безопасные материалы |

Проверка сохранения поведения сравнивает весь Xray JSON, включая DNS, порядок правил, локальные маршруты, BitTorrent, geographic rules и настройки прямого выхода. Разрешено только изменение remarks. Повторное подключение к производственным серверам не выполнялось.

Xray-профиль сохраняет зависимости от установленных у клиента геобаз. Проект их не копирует и не распространяет. Проверка нативными парсерами в CI относится к экспортируемым явным доменным правилам, а не к содержимому геобаз конкретного клиента.

Временный набор из 8 точных хостов был ошибочным изменением масштаба задачи. Он исключён из текущей основной версии. Полный исходный набор восстановлен; его непроверенные заново записи не удаляются из рабочих маршрутов автоматически.

## Независимые наборы

Первоначально добавлены общий набор из 111 доменов и 13 категорий в трёх форматах. Их генератор не обращается к внешним routing-спискам. Полный выборочный Xray-шаблон проверяется отдельным native-тестом без установленных геобаз; прежний совместимый шаблон продолжает проходить проверку сохранения поведения.

Последующая проверка выявила недостаточное покрытие служебных доменов приложений. Текущее отдельное тестовое изменение включает 173 доменов; источники, открытые пробелы и границы проверки описаны в [COVERAGE.md](COVERAGE.md). Прежний профиль и выпуск v1.0.0 остаются замороженными.
