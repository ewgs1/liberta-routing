# Подключение

Liberta Routing направляет выбранные сервисы напрямую, остальной публичный трафик — через proxy. Статус клиента и границы испытаний: [COMPATIBILITY.md](COMPATIBILITY.md). Число доменов и ревизию проверяйте в manifest опубликованного набора.

## Remnawave и Happ

`dist/liberta.xray.json` — генерируемый клиентский шаблон, а не готовое VPN-подключение. Создайте отдельный XRAY_JSON-шаблон и тестовую подписку в панели. Remnawave подставляет outbound `proxy` через `addVirtualHostAsOutbound`. Параметры узлов в публичный проект не добавляют.

Happ передаёт полный Xray JSON ядру без наложения DirectSites из интерфейса. Поэтому правила и DNS для JSON-подписки должны приходить в самом шаблоне. Параметры Tunnel DNS и геофайлов управляются приложением отдельно. Для обычных ключей доступны native-профили в `examples/happ/`: импортируйте строку из `liberta-selective.txt`, выберите профиль и переподключитесь. Вариант FakeDNS остаётся отдельным экспериментом.

Happ поддерживает загрузку собственных GeoSite/GeoIP по URL. Наличие такой возможности не является подтверждением импорта конкретной сборки на конкретной версии iOS.

Локальная интеграция полного конфигурационного файла:

```sh
node scripts/integrate.mjs --mode selective --format xray --base .private/base.json --out .private/test.json
```

Скрипт сохраняет параметры подключения в отдельной приватной копии. Он поддерживает клиентские SOCKS/HTTP слушатели и стандартные теги proxy/direct/block. Неизвестные схемы, существующий FakeDNS и балансировщики требуют отдельной интеграции.

## sing-box и TXT

Источник доменных правил: `rules/liberta-direct.singbox.json`. Сервисные IP находятся отдельно в `liberta-direct-ip.singbox.json`; подключайте оба набора к direct после `liberta-proxy`. Подключите его как source rule-set к вашему direct. Набор `liberta-proxy` применяется раньше direct; итоговый маршрут — proxy. Для remote rule-set используйте опубликованный URL и параметры загрузки, соответствующие версии sing-box. Сам rule-set не задаёт подключение, TUN и DNS.

Доменные правила не перехватывают неизвестные IP вне рассмотренных сервисных CIDR. Это остаётся ограничением выборочного профиля.

`rules/liberta-direct.xray.json` — один объект для routing.rules. Xray не скачивает такой JSON как remote rule-set: его нужно включить в шаблон сборщиком или средствами клиента. TXT содержит `domain:`-суффиксы, а не универсальный файл для всех программ.

## Обновление и приёмка

Файл на GitHub, вставленный вручную шаблон панели и импортированная телефоном подписка обновляются разными механизмами. Сначала публикуется проверенная ревизия, затем обновляется шаблон, затем клиент получает подписку и переподключается. Ревизию необходимо фиксировать по хешу/manifest.

Проверьте Wi-Fi и мобильную сеть: холодный вход в банк, история, открытие СБП до подтверждения; документы Госуслуг; фото, видео и сообщения VK; поиск, карточки и корзина маркетплейсов; зарубежный сайт через proxy. Запишите версии ОС, клиента, ядра и приложения. Открытый экран не доказывает direct — нужны сведения о фактическом маршруте.

Прежний совместимый набор `liberta-v1.*` сохраняет поведение исходного профиля. Он использует геобазы клиента и не является независимой базой выбранных сервисов.

Спецификации: https://docs.rw/learn-en/templates/ ; https://docs.rw/learn/xray-json-advanced/ ; https://www.happ.su/main/ru/dev-docs/routing ; https://www.happ.su/main/ru/dev-docs/examples-of-links-and-parameters ; https://sing-box.sagernet.org/configuration/rule-set/

Обновление одного существующего XRAY_JSON-шаблона панели:

```sh
node scripts/remnawave-sync.mjs --mode plan --uuid TEMPLATE_UUID --plan .private/deploy.json
node scripts/remnawave-sync.mjs --mode apply --plan .private/deploy.json
node scripts/remnawave-sync.mjs --mode rollback --plan .private/deploy.json
```

Адрес панели и токен задаются локально через `REMNAWAVE_API_URL` (без завершающего `/api`) и `REMNAWAVE_API_TOKEN`. План содержит резервную копию и требует приватного хранения. Apply откажется писать, если шаблон изменился после plan. Скрипт обновляет указанный шаблон и проверяет ответ; он не выбирает шаблон за оператора и не заставляет телефон обновить подписку. Неизвестные схемы шаблонов требуют отдельного разбора.
