# Разработка

```sh
npm run build
npm run verify
```

Генерация воспроизводима и не обращается к сети. `rules/`, `dist/` и примеры не редактируют вручную. Для изменения маршрута меняют реестр, происхождение, контроль выбора маршрутов и проверяют diff. Сборка совместимого набора выполняется отдельно и защищена хешем поведения.

Сетевой сбор кандидатов:

```sh
npm run discover -- --service tbank --out .private/tbank.json
npm run discover -- --service tbank --ct true --out .private/tbank-ct.json
npm run discover -- --service wildberries --networks true --out .private/wb.json
```

Отчёт не перезаписывается, маршруты не меняются. Число и размер запросов ограничены. CT и RIPEstat могут быть недоступны; это отмечается в отчёте, а не объявляется полным успешным сбором.

CI проверяет Node на трёх ОС, нативные парсеры Xray и двух версий sing-box, реальные локальные маршруты и выбор DNS-сервера. Выходы и DNS в стендовых испытаниях заменены локальными наблюдателями. Работа приложений на устройстве проверяется отдельно: [COMPATIBILITY.md](COMPATIBILITY.md).

Изменение правил проходит обзор. Сетевые наблюдения и обновление источников не должны сами публиковать новые direct-маршруты. Автоматизация использует минимальные права, закреплённые действия и контрольные суммы инструментов. Параметры инфраструктуры передаются через приватные файлы или окружение.
