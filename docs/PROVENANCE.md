# Происхождение реестра

Сохранена собственная рабочая база Liberta из присланного архива: 13 классов, 111 доменов и прежние explicit-флаги. Готовые сторонние подборки не импортируются.

`registry/registry.json` определяет рабочую маршрутизацию. `registry/provenance.json` содержит запись на каждый из 111 доменов и очередь проверки первичных источников. Неизвестные даты добавления оставлены null; URL для последующего обзора не выдаётся за уже проверенный источник. Pending-review не отключает существующие рабочие маршруты.

Два measured-исключения сохранены. Их подробные сетевые отчёты, точки наблюдения и данные выхода остаются закрытыми. Новый canary проверяет все 111 хостов, отказывается от непубличных DNS-адресов, проверяет TLS и не изменяет реестр.

Результат HEAD-запроса не доказывает работу всего сервиса, наличие цензуры или необходимость сменить маршрут. Изменения рабочих правил требуют отдельного обзора и сравнения с предыдущей версией.
