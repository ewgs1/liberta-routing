# Матрица совместимости

| Среда | Реализовано | Статус |
| --- | --- | --- |
| Xray routing JSON | `full:`, direct allowlist, последний TCP/UDP → proxy | Логические и интеграционные тесты; native job проверяет закреплённый Xray |
| sing-box source JSON | Версия 1, точные `domain`, без маршрута внутри списка | Логические тесты; native job проверяет две закреплённые версии |
| TXT | `full:hostname` по одной записи | Проверено совпадение содержания с обоими JSON; импорт зависит от клиента |
| Remnawave XRAY_JSON | Вставка `routing` в отдельный шаблон с готовым proxy | Инструкция и локальная интеграция; живая панель не проверялась |
| Remnawave SINGBOX | Source/inline в отдельном шаблоне | Инструкция; живая панель не проверялась |
| Android | Ядро Xray или sing-box с нужными полями, DNS и способом получения домена | На устройстве не проверено |
| iOS | Клиент с поддержкой соответствующего JSON/rule-set | На устройстве не проверено; не любой iOS-клиент принимает Xray JSON |
| Windows | Код генератора и синтетические тесты входят в CI matrix | Реальный VPN-клиент не проверен |
| macOS | Код генератора и синтетические тесты входят в CI matrix | Реальный VPN-клиент не проверен |
| Linux | Локальные Node.js тесты и воспроизводимость | TUN и реальные пользовательские сценарии не проверены |
| Существующий Smart v5 | Сохранён compatibility-сборщик, проверена побайтовая регрессия | Совпадает с присланным baseline; живая конфигурация не менялась |

Не ставьте статус «поддерживается и проверено» только по названию ОС. Нужны имя и версия клиента, версия ядра, формат подписки, режим подключения, DNS/sniffing, IPv4/IPv6 и тестовые сценарии. Публичные сведения об этих испытаниях должны быть обезличены.
