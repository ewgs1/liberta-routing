# Совместимость

Состояние проверено 14.11.2026. Парсер ядра и генератор не подтверждают работу приложения на устройстве.

Ревизия и состав правил фиксируются в `rules/manifest.json` и исходном коммите. Сетевой сбор кандидатов имеет отдельный статус и не является проверкой приложений.

| Клиент | Платформа | Версия клиента / ядра | Новый выборочный профиль |
| --- | --- | --- | --- |
| Happ | iOS | Не зафиксирована | Не проверяли |
| Happ | Android | Не зафиксирована | Не проверяли |
| v2rayTun | iOS | Не зафиксирована | Не проверяли |
| v2rayTun | Android | Не зафиксирована | Не проверяли |
| v2rayN | Windows | Не зафиксирована | Не проверяли |
| Hiddify | Android | Не зафиксирована | Не проверяли |
| Hiddify | iOS | Не зафиксирована | Не проверяли |
| Hiddify | Windows / macOS / Linux | Не зафиксирована | Не проверяли |

Для строки «проверено» нужны клиент и версия ядра, ОС и версия, режим подключения, дата, неизменяемый SHA правил и результаты сценариев: вход в банк, Госуслуги, VK с медиа, Яндекс, зарубежный сайт. Для маркетплейсов — вход, каталог и изображения. Закрытые данные подключения в отчёт не включаются.

Владелец сообщил об успешном входе в Т-Банк после изменения своего локального профиля. Клиент, ОС и точная конфигурация испытания не зафиксированы; это отдельный пользовательский результат, а не испытание данного выборочного шаблона.

| Автоматическая проверка | Что устанавливает |
| --- | --- |
| Node 22/24 на Windows, macOS и Linux | Тесты, воспроизводимая сборка, происхождение данных и аудит публичных файлов |
| Xray 26.11.9 | Синтаксис полного выборочного шаблона без геобаз |
| sing-box 1.11.15 / 1.14.4 | Синтаксис source rule-set |
| Xray с локальными выходами-наблюдателями | Корни и поддомены, сервисные IP и отрицательные сценарии: корни и поддомены, proxy-исключения, неизвестные IPv4/IPv6, HTTP Host и TLS SNI |
| Xray с локальными DNS-серверами | Выбор DNS для сервиса, облачного исключения и неизвестного домена; параллельный запрос исключения не попадает в domestic |
| Сравнение совместимого профиля | Сохранение всех прежних полей, кроме имени; переименование файлов без изменения байтов |

Сохранённый совместимый профиль собирается из `registry/compatibility-v1.json`; его 111 исходных доменов, 45 явных правил и полный Xray-конфиг заморожены. Новые независимые наборы собираются из `registry/registry.json`. Публикация канала `release` и изменение производственных подписок выполняются отдельно.

Следующий этап — [испытание Happ на iPhone](USAGE.md). Импорт native-профиля Happ, работа TUN, FakeDNS, QUIC/ECH, сеть только с IPv6/NAT64 и сценарии приложений этим прогоном не подтверждены. Необходимый набор версий и сценариев указан в инструкции; пустые результаты не заменяются отметкой «проверено».
