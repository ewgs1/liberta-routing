# Совместимость

Новые независимые наборы находятся в `rules/`, публикация — в ветке `release`. Полный выборочный Xray-шаблон: `examples/remnawave/liberta-selective.xray.json`. Они не используют страновые геобазы. Описание прежних выходов ниже относится к совместимому профилю.

| Выход | Содержание | Проверка |
| --- | --- | --- |
| Xray / Remnawave JSON | Прежний полный шаблон с новым именем | Все поля кроме remarks совпадают с рабочим исходником |
| sing-box source JSON | 45 явных доменных правил, включая поддомены | Содержание сверяется с явным правилом Xray; parser job использует две закреплённые версии |
| TXT | Те же 45 записей domain: | Совпадение с Xray и sing-box |
| Android / iOS / Windows / macOS / Linux | Зависит от клиента, ядра и формата подписки | Генератор проверяется в CI на Windows/macOS/Linux; новые испытания на устройствах отдельно |

Нативный CI проверяет синтаксис явных правил. Географические данные и полный профиль зависят от окружения клиента. Автоматическая замена подписок и проверка на живой панели не выполнялись.
