# Подключение и проверка

## Xray / Remnawave

`dist/smart.xray.json` — полный прежний шаблон Smart v5 с именем Liberta Routing v1. DNS, порядок правил, 45 явных доменных правил, географические правила, локальные маршруты и блокировка BitTorrent сохранены.

У шаблона есть `remnawave.addVirtualHostAsOutbound: true`: основной outbound proxy подставляет панель. Не добавляйте адреса узлов и параметры пользователей в публичный репозиторий. Для запуска вне панели нужен полный итоговый клиентский конфиг с proxy и установленными геобазами.

Для отдельной проверки переименования полной локальной конфигурации:

```sh
node scripts/integrate.mjs --format xray --base .private/base.json --out .private/renamed-v1.json
```

Команда создаёт отдельный файл и меняет только remarks. Она не переключает профиль и не меняет маршруты или DNS.

## sing-box и TXT

Эти экспорты содержат 45 явных доменных правил, совпадающих с явным direct-списком Xray. Используется совпадение домена и поддоменов: domain_suffix в sing-box, domain: в TXT.

Они не содержат географическую часть, DNS и специальные правила Xray. Их нельзя выдавать за эквивалент всего рабочего профиля. Source rule-set привязывают к direct внутри существующей конфигурации sing-box; оставшиеся правила и маршрут по умолчанию сохраняют и проверяют отдельно.

## Выпуски

Используйте фиксированный проверенный тег. Сначала скачайте новый комплект в отдельный каталог, проверьте контрольные суммы, затем испытывайте отдельным шаблоном/профилем. Проект не переключает производственные подписки автоматически.

Спецификации: https://xtls.github.io/en/config/routing.html ; https://sing-box.sagernet.org/configuration/rule-set/source-format/ ; https://docs.rw/learn-en/templates/
