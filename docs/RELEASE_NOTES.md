# Liberta Routing v0.1.0-alpha

Первый независимый выборочный набор: 8 точных хостов по официальным первичным источникам. Три формата: Xray routing JSON, sing-box source JSON и типизированный TXT. `release.json` содержит SHA256 и границы проверки.

Добавлены строгий реестр с датами/источниками, diff маршрутов и route-lock, неизменяемая детерминированная сборка, проверка целостности загрузки, ограниченный canary без изменения данных, public scan, тесты и проверка нативных парсеров в release workflow.

Присланный Smart v5 воспроизведён побайтово; compatibility-сборщик сохранён, исправлен небезопасный допуск measured-исключений без успешного домашнего baseline. Его закрытый реестр и диагностические данные в публикацию не входят.

Alpha предназначена для отдельного тестового профиля. Полные сценарии сервисов, региональная доступность, работа на мобильных устройствах и живая интеграция Remnawave не подтверждены. Она не заменяет весь Smart v5 и не включает подключения к VPN-узлам.
