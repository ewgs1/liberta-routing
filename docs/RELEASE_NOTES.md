# Liberta Routing v1

Первый тестовый набор: 8 точных хостов с официальными источниками. Xray JSON, sing-box source JSON и TXT.

Есть проверки схемы, маршрутов, целостности, нативных парсеров и отдельная регрессия Smart v5. Рабочие подписки автоматически не меняются. Региональные и мобильные испытания продолжаются.
