# Liberta Routing v1

Рабочий Smart v5 переименован в Liberta Routing v1. Сохранены 13 классов, 111 доменов, 45 явных direct-записей и прежние правила Xray/DNS.

Добавлены безопасная проверка canary baseline, тесты сохранения поведения, экспорт явного списка в sing-box source JSON и TXT. Метаданные VPN-узлов и сырые диагностические материалы исключены из публичной части.

Статус: тестирование. Замена производственных подписок автоматически не выполняется.
