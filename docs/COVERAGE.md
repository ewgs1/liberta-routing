# Покрытие приложений

Сравнение с предоставленным пользователем фрагментом показало 1199 доменных записей direct против 111 в исходной базе Liberta. В том фрагменте нет IP-правил. `IPIfNonMatch` сам по себе не добавляет российские сети. Чужой фрагмент, список и параметры подключения в репозиторий не импортированы.

Подтверждённые пробелы исправляются по первичным документам; число записей не является показателем полноты приложения. Текущий тестовый набор вырос до 120 доменов. DNS-список, категории и три формата генерируются вместе. Рабочий совместимый профиль и опубликованный релиз v1.0.0 сохранены.

`yandex.ru` уже покрывает market.yandex.ru, music.yandex.ru и travel.yandex.ru. Эти поддомены проверяются в регрессии без отдельных дублирующих строк.

Остаются открытыми:

- Из отчёта Т-Банка: data-tscbank.ru, cdn-tinkoff.ru, t-calls.ru, t-tolk.ru, tbank-online.com, tinkoffmobile.ru — не внесены этим изменением, обзор достаточных первичных подтверждений не завершён.
- Из запроса покрытия VK и Дзен: dzen.ru, userapi.com, mycdn.me, vkuser.net, vkuseraudio.net, vkuserlive.net — обзор зависимостей не завершён.
- Для маркетплейсов: ozonusercontent.com, wb-basket.ru и wbcontent.net — нужна проверка конкретных API/CDN-запросов. Добавления ozone.ru и wbbasket.ru не закрывают эти другие домены.
- sbp.ru — отклонён как банковское исключение: https://sbp.ru/ представляет туристическое бюро. НСПК указывает https://sbp.nspk.ru/ как официальный сайт СБП: https://www.nspk.ru/about/official_sites . Его покрывает уже имеющийся nspk.ru.

Одновременное изменение восьми доменных правил и DNS с последующим успешным входом подтверждает пользовательский результат пакета изменений. Оно не устанавливает единственный обязательный домен, не доказывает соединения по голому IP и не подтверждает блокировку всех зарубежных адресов.

В выборочном шаблоне неизвестный публичный IP без восстановленного имени идёт в proxy. Известное имя может быть получено из запроса клиента или сниффинга HTTP/TLS. Этот механизм не гарантирует покрытие любого протокола. Работа приложений, Android/iOS, UDP/QUIC и TLS/ECH требуют самостоятельных испытаний. До них шаблон остаётся тестовым.
