# Сохранение Smart v5

Проверены присланные исходники и сохранённая конфигурация Smart v5. В исходном реестре 13 классов и 111 уникальных доменов; 43 домена имеют классовый `explicit: true`, ещё 2 — измеренные исключения. Всего в явном direct-правиле Smart v5 45 записей. 45 — не размер всего реестра.

## Проверка регрессии

Исходный сборщик запущен без сетевых опций, с исходным реестром. Полученный JSON и исходный `smart-v5.generated.json` совпали. Сохранённый `dist/smart.xray.json` имеет те же байты.

SHA256 исходного и повторно собранного Smart v5:

`399e02f737cc97bab29cdbbe54a145269c091048dd6cbd099435f44dd16e219d`

В [scripts/build.mjs](../scripts/build.mjs) сохранён compatibility-сборщик. Нормальная сборка без новых canary-данных даёт тот же результат. Исправлен только допуск новых measured-исключений: зарубежный отчёт требует домашнего baseline, а конкретный домен добавляется только при `ok`/`redirect` в этом baseline. Пустой или неуспешный baseline больше не разрешает добавление. Значения по умолчанию для входа и выхода направлены в `.private/`, чтобы случайно не опубликовать старый реестр или профиль.

```sh
npm run verify:legacy
```

Проверка ожидает исходную копию в `.private/legacy/`. Она не включена в публичный репозиторий, так как содержит внутренние данные. При отсутствии baseline проверка явно сообщает, что не выполнена. В публичном CI отдельно выполняются синтетические тесты трёх вариантов baseline, без частных данных.

Это проверка воспроизводимости и отсутствия изменения конфигурации, не новый end-to-end тест Smart v5. Работающее подключение пользователя не активировалось и не менялось.

## Отличие выборочной alpha

Smart v5 направляет трафик напрямую и по явным доменам с поддоменами, и по широкой географической базе. В нём согласованы DNS, правило BitTorrent, локальные имена, адреса DNS-резолверов, приватные адреса и последний маршрут `proxy`. В Remnawave `proxy` добавляется панелью.

Alpha экспортирует самостоятельный маленький список точных хостов. Широкие country/geosite/geoip-правила из Smart v5 в неё не перенесены. Проверить файл alpha вместо всего рабочего профиля нельзя: в нём нет DNS, слушателей и подключения.

Отдельный тестовый профиль создаётся из копии конфигурации и не заменяет Smart v5 автоматически. DNS, системные сервисы и специальные маршруты нужно проверить по [INTEGRATION.md](INTEGRATION.md).
