# Переименование без изменения поведения

Присланный Smart v5 первоначально воспроизведён побайтово. SHA256 исходной конфигурации:

`399e02f737cc97bab29cdbbe54a145269c091048dd6cbd099435f44dd16e219d`

В Liberta Routing v1 изменяется только remarks. После возврата старого remarks повторно собранный JSON имеет тот же SHA256. Контрольная сумма всего поведения без remarks и состава реестра закреплена в test/fixtures/production-lock.json.

Сохраняются все 111 доменов, 13 классов, explicit-флаги, два measured-исключения, DNS, порядок и состав routing.rules, слушатели и выходы. Удаление метаданных nodes из публичного реестра на сборку не влияет.

`npm run verify:legacy` дополнительно сверяет закрытую исходную копию. Публичные тесты используют безопасные контрольные суммы и тестовые данные. Производственная конфигурация пользователя автоматически не меняется.
